# TP 2 — Application Web LangChain4j

Camel Chafii — EMSI CASA-IA G2.

Deuxième partie du [TP 2 de Richard Grin](http://richard.grin.free.fr/emsi/casablanca-ia/tp/tp2-langchain4j/index.html) : chat JSF avec Jakarta EE 11, PrimeFaces et LangChain4j. Le projet des sept tests en console reste séparé.

Prérequis : JDK 25, Maven et un serveur compatible Jakarta EE 11, par exemple Payara Micro 7. La clé Gemini doit être fournie par une variable d’environnement, jamais dans le code.
